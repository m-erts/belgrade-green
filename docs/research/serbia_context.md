Заменил Правилник 50/11 (чл. 66).
- **Главный вывод: минимального процента зелёных площадей на участке этот Правилник НЕ устанавливает.** В полном тексте (поиск по «зелен», «зеленил», «озелен», «%») зелень упоминается только дважды:
  - чл. 37 (ограждения): «Суседне грађевинске парцеле могу се ограђивати живом зеленом оградом која се сади у осовини границе грађевинске парцеле…»
  - чл. 47 (сельская зона, участок на склоне): отступ «…увећаним за најмање 3,00 м зеленог простора.»
- **Что Правилник реально нормирует по зонам (чл. 36)** — максимальный индекс застройки (индекс заузетости) и индекс плотности (индекс изграђености). Цитата: «Највећи дозвољени индекс заузетости по зонама изградње је за: 1) зона кућа за одмор - 25%; 2) сеоска зона - 30%…»
  - индекс заузетости (макс.): зона кућа за одмор 25%; сеоска зона 30%; зона ретких насеља и породичне градње 40%; општа стамбена зона средњих густина 50%; мешовите зоне средњих густина 50%; градске стамбене и опште зоне већих густина 50%; централне градске и пословне зоне 60%; периферне пословне, привредне и индустријске зоне 60%.
  - индекс изграђености (макс.): 0,3 / 0,8 / 1,2 / 1,6 / 2,0 / 2.8 / 3,5 / 1,5 — в том же порядке зон.
- **Следствие для постов:** «зелёная доля» участка по этому Правилнику может быть получена только косвенно (100% − индекс заузетости = незастроенная, но не обязательно зелёная часть). Конкретные минимумы «% зелених површина» на участке задаются планами (ГУП/ПГР/ПДР), а не этим Правилником — см. 1b.
- **Статус:** **VERIFIED** (первоисточник — официальный текст на mgsi.gov.rs; отсутствие изменений — по paragraf.rs, это вторичный, но надёжный правовой агрегатор). Портал pravno-informacioni-sistem.rs (https://pravno-informacioni-sistem.rs/viewAct/d877c55a-ad73-4978-acee-2f4a3b214497) не отрендерился без JS — актуальность редакции там не проверена.
